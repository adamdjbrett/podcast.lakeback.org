# podcast.lakeback.org

Coming-soon page for *Healing the Sacred*, a podcast from the American Indian Law Alliance.

Run `npm install`, then `npm run dev`. Open [http://localhost:8080](http://localhost:8080) for the local preview. Run `npm test` to check the countdown and `npm run build` to generate the static site in `dist/`.

Edit homepage content and launch settings in `src/_data/metadata.yml`. Use an ISO timestamp with an explicit UTC offset for `launch.at`. The build formats the displayed schedule in `launch.zone`. The schedule also works with JavaScript disabled.
